The 8-Puzzle problem

The puzzle is a 3 x 3 grid holding tiles 1 to 8 and one blank. A move slides a neighbouring tile into the blank, which is the same as moving the blank up, down, left or right. The task is to turn the initial arrangement into the goal arrangement.

As a search problem: a state is one arrangement of the nine cells; the actions are the legal blank moves (2 to 4 per state); each move costs 1; the goal test compares a state with the goal. Only half of all 362,880 arrangements can reach any given goal, so the app checks solvability by counting inversions. This project solves it with Depth First Search and compares it with BFS, DLS, IDDLS, GBFS and A*.

Puzzle input

Type digits 1 to 8 and leave one cell empty (or enter 0 or _) for the blank.
